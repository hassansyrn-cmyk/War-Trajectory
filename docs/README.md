# War Trajectory Mobile (WTM) - Documentation Suite Index

Welcome to the **War Trajectory Mobile (WTM)** official Game Design and Technical documentation suite. This repository houses complete, high-fidelity production documents detailing WTM, a competitive 1v1 turn-based, physics-based PvP tactical mobile shooter developed in Unity 3D with Photon Fusion.
